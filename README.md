# AREA-CALCULATION-FOR-SHAPES-IN-ANDROID
📐 Area Calculation for Shapes in Android

An Android application developed to calculate the area of different geometric shapes including Square, Rectangle, Circle, and Triangle. This project demonstrates Android Activity navigation, UI design, and basic mathematical calculations.

🚀 Features

✅ Calculate area of multiple shapes:

Square

Rectangle

Circle

Triangle

✅ Simple and user-friendly UI

✅ Separate Activity for each shape

✅ Result display screen

✅ Clean navigation between screens

📱 App Screens

Main Menu (Shape Selection)

Square Area Calculator

Rectangle Area Calculator

Circle Area Calculator

Triangle Area Calculator

Result Display Activity

🛠️ Technologies Used

Java

Android Studio

XML Layout Design

Android SDK

Intent-based Activity Navigation
